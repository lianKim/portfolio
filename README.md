## Tech Stack

- **Framework**: Next.js 16
- **Language**: TypeScript
- **Styling**: Tailwind CSS, shadcn/ui
- **Content**: MDX (next-mdx-remote)
- **Comments**: Giscus
- **Deployment**: Vercel

<br />

## Getting Started

> Node.js 20.9+

```bash
# 의존성 설치
yarn install

# 개발 서버 실행
yarn dev
```

http://localhost:3000
